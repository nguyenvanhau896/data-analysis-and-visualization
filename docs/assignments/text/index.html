Vietnamese Student Feedback Sentiment Classification

An end-to-end text classification project using the UIT-VSFC corpus, TF-IDF representations, Logistic Regression, and Linear SVM.

View rendered notebook Notebook source

Problem & dataset

Task: classify Vietnamese student feedback as negative, neutral, or positive.

Dataset: UIT-VSFC (Vietnamese Students' Feedback Corpus).

Scale: more than 16,000 labeled text samples with predefined train, validation, and test splits.

License of mirror: CC BY-NC-SA 4.0.

Open dataset source →

Methods

Unicode normalization and lightweight text cleaning.

EDA: class balance, text length, missing values, duplicates, and examples.

Models: majority baseline, word TF-IDF + Logistic Regression, and character TF-IDF + Linear SVM.

Evaluation: Accuracy, Macro-F1, Weighted-F1, confusion matrix, and error analysis.
