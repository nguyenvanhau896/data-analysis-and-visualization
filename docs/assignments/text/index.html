Understanding student feedback with sentiment classification

An end-to-end text analysis of the UIT-VSFC corpus, from data checks and Vietnamese text normalization to TF-IDF model comparison and error analysis.

Explore rendered notebookDownload notebook source
Question & data

Can a model read the sentiment?

Task: classify Vietnamese student feedback as negative, neutral, or positive.

Dataset: UIT-VSFC (Vietnamese Students' Feedback Corpus), with predefined train, validation, and test splits.

Data mirror: CC BY-NC-SA 4.0 as described by the dataset host.

Dataset card →
Approach

Compare, then inspect

  • Validate splits, labels, duplicates, and text lengths.
  • Normalize Unicode and clean URLs, email addresses, and whitespace.
  • Compare a majority baseline with word and character TF-IDF models.
  • Select using validation Macro-F1, then evaluate on the held-out test set.
  • Review confusion pairs and influential terms to understand errors.
