Who accepts an in-vehicle coupon?

We analyze driver, trip, and coupon context to understand acceptance and compare eight classification configurations on a held-out test set.

Question & data

Predict coupon acceptance

Target: whether the driver accepts the presented coupon (binary label Y).

Dataset: UCI In-Vehicle Coupon Recommendation, with driver context, destination, weather, time, and coupon details.

UCI dataset source →
Workflow

From raw rows to evaluation

  • Remove exact duplicates and create train, validation, and test splits.
  • Explore missingness, class balance, and acceptance by key categories.
  • Impute, one-hot encode, and scale using training data only.
  • Compare eight model configurations using validation performance.
  • Evaluate the selected model once on the held-out test set.
